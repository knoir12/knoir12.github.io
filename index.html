about

i am Jean Roy Lastimosa, a software engineer and licensed electronics technician (ECT) with a B.S. in Electronics Engineering from Cebu Institute of Technology – University.

i mostly build full-stack web applications, backend services, and computer vision / data pipelines. day-to-day i work with python + javascript/typescript. i use node.js, fastapi, flask, and django for backend work, react and next.js for frontend, and swap between postgresql, mysql, and sqlite depending on the project.

beyond web and backend engineering, i enjoy integrating software with real-world hardware and datasets—working with opencv, yolo, linux, and embedded systems like raspberry pi, jetson nano, and arduino.

experience

  • web developer (front-end & back-end) (march 2022 – present): building responsive web apps, REST APIs, and SQL database integrations using react, next.js, node.js, and mysql across 10+ client projects.

  • back-end developer intern @ CIT-U R&D coordinating office (june 2023 – august 2023): engineered real-time sensor telemetry pipelines, SQL logging systems, and linux edge-device communication for autonomous robotics using python, java, and lidar.
